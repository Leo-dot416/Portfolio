# Portfolio

This repository is a collection of programs that I have created to show off my skills and my abilities.

It is organized as a growing personal portfolio where I can add projects in different programming languages and demonstrate both technical depth and problem-solving style over time.

## Repository Structure

- `AI_Assistant` — Project where the user can type in questions and an AI will answer the questions based on some knowledge given to it using a small database .
- `website/` — A portfolio-style website to showcase completed and upcoming programs.

## Purpose

The goal of this repository is to document my progress, highlight what I can build, and provide a clear, professional space where others can explore my work.
